First public build of **SSX3-Recomp**: a native PC port of **SSX 3 (original Xbox, 2003)**, made by statically
recompiling the game's Xbox code to C with [xboxrecomp](https://github.com/sp00nznet/xboxrecomp). No emulator.

This is an **early, experimental** release: the game boots and races play, but a lot is still untested.

> ⚠️ **No game files included.** You need your own, legally obtained copy of SSX 3 for the Xbox, **PAL/EU
> version** (title ID 4541003C). Other versions do not work. Never share game files.

## Getting started

1. Download the package for your system below and unpack it.
2. Dump your SSX 3 Xbox disc to an `.iso` and extract it into the package's `game_files/` folder with
   [extract-xiso](https://github.com/XboxDev/extract-xiso) or [xdvdfs](https://github.com/antangelo/xdvdfs):
   `extract-xiso -x "SSX 3.iso" -d game_files` – afterwards `game_files/default.xbe` and `game_files/data/` must exist.
3. Start the launcher:
   - **Linux:** `./run.sh` – asks for internal resolution, frame rate and v-sync on the first start (saved for later)
   - **Windows:** double-click `run.bat` (runs `run.ps1`)

**Linux** needs glibc 2.39+ (Ubuntu 24.04+, Fedora 40+, Arch, SteamOS 3.6+), SDL2, OpenSSL 3, libepoxy and a
Vulkan driver (`sudo apt install libsdl2-2.0-0 libssl3 libepoxy0 mesa-vulkan-drivers`).
**Windows** needs Windows 10 or 11 (x86-64).

## What works

- Boot with EA / THX logos (skipped by default) and the intro movie
- Audio through the emulated Xbox APU
- Title screen, menus, character select
- **Races start and play**; graphics match the reference software renderer
- Keyboard as player 1, XInput/SDL controllers with hotplug and rumble

## Features

- **Vulkan renderer** (Linux): 60 fps in menus, 55–60 fps in races (the software renderer manages ~15 fps)
- **Frame interpolation above 60 fps**: the game simulates at 60 and is shown at your display's refresh
  (tested at 120 and 270 Hz) or a fixed 120/144/165/240 fps cap, or uncapped
- **Internal resolution 1x–5x** (640x480 up to 3200x2400), F10 cycles it in game
- **Start-up menu** for resolution, frame rate and v-sync; the choice is saved and reused (also from a Steam shortcut)
- **Controllers**: Xbox 360/One/Series, 8BitDo (X-input), Steam Deck controls via Steam Input, anything SDL2 knows;
  plug in at any time; the game's force feedback goes to the pad's motors
- Skippable logos and intro (`SSX3_SKIP_LOGOS`, `SSX3_SKIP_INTRO`)

## Known issues and limitations

- **Windows is experimental**: it uses the software (CPU) renderer only, which is slow – the Vulkan renderer has no
  Windows surface yet. The resolution/frame-rate options do not apply there.
- A full run through the game (all peaks, Conquer the Mountain, saving) and split screen are **not verified** yet.
- Occasional crash right after the intro movie starts – start again.
- The pre-race screen and very busy race scenes drop below 60 fps.
- Some rare graphics effects are missing in the Vulkan renderer (cube maps beyond face 0, bump-env modes,
  palettised textures).
- Not tested on a Steam Deck yet.
- No widescreen, anti-aliasing or HD textures yet – planned.

Please report bugs at [Issues](https://github.com/bertibertig/SSX3-Recomp/issues) with the console output
(`./run.sh 2>&1 | tee run.log`).
